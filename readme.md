# Macondofetch
Macondofetch is a neofetch-like tool built for Hack Club Macondo that uses the Macondo API
## Features
- Colors!
- Nice ASCII art of the Macondo logo or whatever
- API usage that works as of July 12th, 2026
## How do I use it?
- Windows
    - Download dist.zip, and put your api key in .env inside the unzipped folder
    - Preferably use the VSCode or the new terminal app for modern colors
- Other (or running from source)
    - Install python, and via pip, install requests
    - Clone the git repo
    - Put your api key inside .env
## What did you learn during this project?
I learnt the following:
- JSON parsing from requests
- Carriage returns
- ANSI colors and how they work
- Actually making nice ASCII art
